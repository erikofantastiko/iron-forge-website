# SEO follow-up: owner actions

The on-page SEO is done in code (entity JSON-LD, an FAQ section, sitemap, robots.txt,
canonical, Open Graph). The remaining work is owner actions that cannot live in the
repo. This file tracks them so they are not lost in a chat log.

Context: the site was invisible on Google even for its own name. Searches for "Iron
Forge" surface unrelated apps that share the name, so the goal is first to get indexed,
then to win the brand terms ("Iron Forge app", "ironforge.app"). Generic terms like
"workout tracker" are not a realistic target before launch.

## Done

- [x] Verify the `ironforge.app` domain in Google Search Console.
- [x] Request indexing of the home page in Search Console (URL inspection).

## How to check progress (no self-googling)

- Search Console, Page indexing: shows when the home page is actually in the index.
- Search Console, Performance: shows which terms bring impressions. First realistic win
  is rank 1 for "Iron Forge app" and "ironforge.app", not generic terms.

## Timing

Indexing takes a few days to a few weeks. That is normal. If nothing shows in Search
Console after two to three weeks, open the Page indexing report and check for errors.
